# 拼船海钓 · P0 页面流程一页纸 v1（2026-10-23）

主线一句话：**看船 → 选活动 → 选钓位 → 付款（含保险）→ 出航 → 评价晒渔获**。所有页面围绕这一条线，工具信息（风/浪/潮汛）只嵌在活动页与出航页，不单独成站。

## 钓友侧（小程序）

**1. 首页**
- 顶部：定位码头/海域切换 + 明日出钓卡摘要（海况红绿灯、黄金潮时）
- 主体：活动流（按日期/码头/鱼种筛），每张活动卡=船图、船长名+口碑分、出航时间、目标海域、已订 X/钓位总数、每位价格、成团状态标签（已成行/还差 N 人/处置中）

**2. 船档案页**
- 船长实名与资质徽标（证件已验/责任险在保）、设施清单、实拍图、钓位总数、停泊码头（地图）
- 口碑区：历史渔获（带海况快照）、空军率、准时率、评价（仅真实订单可评）
- 该船未来活动列表 + 关注按钮（未拼满推送靠它）

**3. 活动详情页**
- 海域/钓场、出发返港时间、目标鱼种、集合码头与导航
- 当日海况条：风速风向、浪高、潮汐曲线与黄金潮时、出钓指数
- 规则明示：最低成行人数、取消/改期规则、保险说明（保额与承保方）

**4. 选位页**
- 船体俯视图选钓位（1–8 号），已订置灰；分位定价直接标在座位上
- 选位后填乘船人实名信息（姓名+身份证号+手机号，一人一位）——同时用于保险投保与出海报备名单

**5. 支付页**
- 明细分行：船位费 / 保险费（独立列示，承保公司与保额可见）/ 平台服务费（如有）
- 支付成功=锁位+保单生成，保单号可在订单里查

**6. 订单/出航页**
- 行程状态条：待成团（已订 X/最低 Y）→ 已成行 → 待出航 → 已返港，全程透明
- 未拼满时在此页内走处置协议（见下），所有选项都是页内确认，不跳出
- 出航日：集合点导航、船长电话、海况终检（过红线自动转取消/改期流程）、电子名单凭证

**7. 返港后**
- 渔获打卡：拍照自动带入当日海况快照 → 同步进船档案口碑区
- 评价：星级+标签（找鱼准/服务/船况），仅已完成订单可评

## 船长侧（同一小程序内切换身份）

**8. 工作台首页**：明日海况出船决策卡（红绿灯+指数）、待处置行程提醒、本周订单与收入
**9. 发活动**：选海域、时间、目标鱼种、每位价（可分位定价）、最低成行人数、整船包船价
**10. 名单与回填**：本航次实名名单（可导出报备）、返港后回填渔获（鱼种/量级/空军如实填，与钓友打卡对账）

## 未拼满处置流程（订单页内，截止点默认出航前一日 18:00）

未达最低成行人数 → ①推送船长：少人成行？（确认即锁定）→ 否 → ②推送已订钓友：每人补 ¥X 保行程（征集意愿，达船长底线才扣款；不接受者全额退）→ 仍不足 → ③开放包船兜底（整船价，散客全退+补偿券；包船方可选保留散客）→ ④自动取消全额退 + 推荐同码头同期活动。

## P0 不做

全国社区/动态广场、渔具商城、会员体系、多海域、原生 App（形态默认小程序先行，待创始人最终拍板）。
