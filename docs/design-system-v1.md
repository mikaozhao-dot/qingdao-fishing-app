字体使用系统中文无衬线；骨架页面标题使用 23 逻辑像素 / `w900`。Flutter 最高字重为 `w900`，视觉稿中更高字重以此近似，业务页面仍按冻结稿逐屏实现。间距按 4 像素步进；卡片圆角 22，导航与身份切换使用胶囊圆角。客户端一级 Tab 固定为首页、活动、订单、我的；船长端为工作台、发班、行程、我的。两身份在同一 App 内切换。

第 0 步只搭空页与后端健康检查入口，不将设计稿中的样例订单、船舶、渔获或气象数值当作真实数据。开发后续业务页面时，要同时处理 Muse 冻结评审列出的四项样例数据与导航小项。
