## 待批/待核实（未获批，不得实施或对外承诺）
- **第 5 步切片 1｜双源渔获分歧口径待创始人选择**：事实型展示与保留双方原始记录已有批准；是否把数量差异自动标成“待核对”尚未批准。依据：船长按整艘船回填、乘客按本人回填，选择性漏报和个体差异可能造成误报。可选：A. 数量任何方向不同、鱼种缺项或明确异议均待核对；B. 当前沙盒实现，仅乘客数量更高、鱼种缺项或明确异议待核对，数量较低不自动冲突；C. 仅乘客明确异议时待核对，纯数量差异只并列展示。B 是当前待审实现，不代表推荐或批准。创始人选择前不得把状态用于惩罚、排名或对外能力判断。
