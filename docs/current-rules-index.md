| 主题 | 现行口径 | 依据 |
|---|---|---|
| 抽佣 | 平台票款抽佣 10%（包船同），推广单推广佣金 5% | 正本 §十六、创始人定版 |
| 退改阶梯 | 以出航时刻 T、左开右闭：>72h 免费；(24h,72h] 扣 30%；(6h,24h] 扣 60%；≤6h 与爽约不退。违约金全归船长、平台不抽，先入班次补偿池 | 正本 §二十二 |
| 成团门槛 | **整航次净到手门槛（B1）**：船长设定；成行核算＝平台票款净额（扣佣后）＋违约金池＋已支付成功补差 ≥ 门槛 | 审批记录 A（2026-10-24） |
| 核算双账 | 平台可核验账才支撑自动达标/成行；线下台账不用于自动宣布达标，只供有记录的船长确认路径（文案"船长已确认成行"）。平台核算门槛≠平台补足差额或担保船长收入 | 审批记录 B、C03 |
| 补差 | **一期一轮制**：候补先处理→冻结名单/资金快照/缺口→每席一次明确报价→全员确认后付款→全部支付成功且服务端复验通过才成行；意向不算钱。退出/失败/超时整轮失效，不自动第二轮加价；失效轮资金在退款义务产生时即退出可用资金；迟到成功回调记账并补偿退款，不滚入新轮。补差不抽佣，支付费平台承担。拒绝补差退出＝全额退款、不扣违约金 | 审批记录 A、P01 |
| 价格冻结 | 票价与门槛首单前冻结；有订单后不得默改价格/门槛规避佣金，变更走批准的重新报价流程 | 审批记录 A |
| 库存 | **配额隔离**：每航次平台专售席位与船方线下席位互不混卖；调额＝先冻结来源未售席位→登记→开放目标侧；已售/已锁不可调走；重复调额不增库 | 审批记录 B、P02 |
| 保险 | 平台只给接口不经手保费；意外险必买、外链出单。**门禁原则（已批）**：保障未核实/未生效者不得登船，外跳成功页不是放行依据；单人问题先阻断该乘客，航次整体必需保障缺失才阻断整船；不得临时强迫其余乘客再补差 | 审批记录 D、正本 §十五 |
| 信用 | 试点只展示事实（分项评价、样本量、时间窗、回填缺失与争议比例），**不做精确排名**；复订率分子＝再次完成出航；能力随船长、船况设施随船档案；评价保留原船长—船只—航次关系 | 审批记录 C、P03 |
| 试点 | 1–2 码头、6–10 船长、连续 4 周（≥3 个周末）、计划班次 ≥40 班；成团扩张线 ≥60%/停止线 <40%，可控履约 ≥90%/<80%（初始经营假设，非行业标准）；样本不足不通过；安全/重大资金事件优先；全条件满足才提扩张、不自动 | 审批记录 E、P05 |
| 模型数字 | 首季情景（假设：3,500 单×3 席×480 元）：零保险时扣直接成本后贡献 398,160 元，减获客预算后 −51,840～+48,160 元；**不是净利润、不是实际经营结果**；保险合同情景 +47,250 元单列 | 审批记录 E、R01 |
| 直播 | 第 5 步：绑抖音号、出航中班次自报开播挂"直播中"徽章、深链跳抖音；不内嵌、不自营 | 正本 §二十五 |
