# 拼船海钓 App · 深海霓虹设计系统 v2

视觉依据为 `design/reference-voltbank-style-muse-v2.html`。本稿使用 A「深海霓虹」：深海墨绿底、荧光柠檬绿作唯一高亮、波纹与潮汐线条、强字号层级和悬浮胶囊导航。四屏风格对比中未选用的蓝白卡、石墨极简和蓝紫方向不进入本稿。

状态色只作小面积信息提示；视觉焦点仍归荧光绿。船图与鱼图均使用真实本地照片，不用渐变替代照片。

## 字阶与字重

字体栈：系统无衬线、`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`。页面标题 23 px / 900；模块标题 14–19 px / 800–850；正文 10–12 px；字段标签与照片署名 8–10 px。出钓指数 44 px / 900，活动价格 20–26 px / 900，成团人数 32 px / 950，口碑分 23 px / 950。数字与单位保持同一行，价格不拆行。

## 间距、圆角与层次

- 基础间距采用 4 px 倍数；卡片内边距 12–16 px，模块间距 8–12 px，屏幕水平留白 15–18 px。
- 内容卡片圆角 22 px；大图与英雄卡 22–30 px；筛选标签、胶囊和底部导航使用完整圆角。
- 卡片通过深绿表面、细边框和低对比投影分层；不使用高亮边框包围所有字段。
- 英雄卡以深绿波纹色面与三列网格表现出钓指数和海况；每个指标标签与数值分两行。

## 组件规范

- **活动卡**：实际船图、船名/出发信息、单人价格、船长评分、预订人数和成团状态同卡呈现。价格、评分和成团人数使用最大字号或高亮色。
- **口碑条**：显示真实订单评分，并按内容原型口径展示出海趟数、空军率、复订率和平均渔获；不将样例数值描述为实时生产数据。
- **成团进度**：进度条、已订人数/总座位、距最低成行人数或满员差额分开表述；`还差 N 人成行`与`已成行`使用单行胶囊状态。
- **筛选标签**：固定单行，不换行、不竖排；窄屏横向滚动。标签文案按需截断而不改变筛选维度。
- **选位图**：纯二维俯视，船头在上；船头、过道、船尾三段。两舷共 12 个固定位置，左侧从船头往船尾为 1–6，右侧从船尾往船头为 7–12；6 / 7 为尾部两角加价位。已售座位禁选，点选空位更新价格。
- **订单确认**：平台船位费、优惠、平台服务费和平台应付逐行列出。保险只提供前往承保公司页面的外部按钮，保费不进入平台金额。退改阶梯在付款按钮之前完整展示。
- **身份切换**：钓友端与船长端在一个 App 中切换。导航中的工作台与发班页直接展示船长端身份。
- **推广面板**：扫码、注册、首单和行程完成分层；累计、可提现、冻结金额分开显示。佣金仅与真实成交有关，完成行程后冻结 7 天，自购不计佣、退款回滚、不设下级返利。

## 十屏导航

`design/ui-v2-full.html` 含十个可切换屏幕：①客户端首页 ②活动列表 ③活动详情 ④选钓位 ⑤订单确认 ⑥我的 ⑦鱼种详情 ⑧船长工作台 ⑨船长发班 ⑩推广中心。桌面端可用左侧导航、上一屏/下一屏按钮或键盘左右方向键；移动端可用顶部横向导航。各屏底部胶囊 Tab 与主要 CTA 可跳转到相关页面。
