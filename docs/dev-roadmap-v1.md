# 拼船海钓 App 开发路线图 v1（一步一步来，每步一验收）

原则：一步一任务书入仓 → Codex 开发 → Muse 实跑评审 → 创始人验收关键步 → 再下一步。不并行多步、不跳步。每步交付物必须是能真跑的东西，不是半成品页面堆叠。

## 第 0 步 · 地基
Flutter 工程骨架（按 B 方案设计系统落 tokens 与组件）、后端单体服务（建议 Go 或 Node + PostgreSQL + Redis，国内云）、环境与发布流水线、数据模型 v1（用户/船/班次/订单/钓位库存）。
验收：双端真机跑起空壳 App 并连通后端健康检查。

## 第 1 步 · 账号与船档案
用户注册/登录（手机号）、实名；船长入驻：船档案登记（船名/长度/登记信息/照片/设施勾选/默认集合码头）、平台审核（最小管理后台）。
验收：能完整录入并审核通过一条真实船，舒适度与选位模板按长度自动生成。

## 第 2 步 · 发班与活动展示（只读闭环）
船长发班（全选择题表单、鱼种必选多选、钓组预设带出、最低成行总价、一键复发）；系统按统一模板生成活动页；客户端首页/列表（五维筛选）/详情（口碑占位、海况卡、钓组配置、成团状态）。
验收：以真实船数据发一班，客户端完整浏览到详情页。

## 第 3 步 · 交易闭环
选位（二维定版图、座位实时状态、锁位 10 分钟）、下单实名校验、微信/支付宝支付、保险外链跳转与投保状态回查、订单状态机。
验收：真机完成一笔小额真实订单（含保险真实出单）。

## 第 4 步 · 成团与履约
成团核算与确认点（前一日 18:00）、未拼满处置链（少人成行/平摊补差/包船兜底/取消全退）、阶梯退改与违约金池、候补递补、行前清单推送、出航/返航打卡、实名名单导出（报备与保险共用）。
验收：模拟一趟含「4 人取消」的班次全流程，处置与退款金额全对。

## 第 5 步 · 口碑与内容资产
渔获回填（船长+乘客双源交叉）、返港评价与结构化标签、口碑计算（空军率/复订率等）、鱼种图鉴点亮与鱼种详情页聚合、大鱼榜、直播状态（2026-10-24 创始人定版，计划正本 §二十五：船长绑抖音号，出航中班次自报开播挂「直播中」徽章，点击深链跳抖音观看；不内嵌播放、不自营直播，零带宽；虚假标记举报下线）。
验收：一趟结束，船长口碑与用户图鉴数据正确沉淀。

## 第 6 步 · 推广与会员
推广中心（推广码/带码海报/归因/一级佣金冻结与提现、防刷规则）、会员等级与券、渔获证书（带推广码）、包船专属入口与订金尾款担保。
验收：一条推广链从扫码到佣金解冻全程可追。

## P1（旺季前增项）
明星船竞拍、临期空位、AA 分账、装备租赁、加工餐厅、团建包船、多船管理、保险升级购。

## 并行线（不占开发步骤，专人盯）
苹果开发者账号与 App Store 审核、App 备案与安卓各市场、保险三路询价与签约口径、船长 BD 与全年合作签约、内容线（实测船长/素人首钓）预热。
