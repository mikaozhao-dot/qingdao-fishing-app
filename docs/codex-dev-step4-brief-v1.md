# Codex 开发任务书 · 第 4 步：成团与履约

依据《开发路线图 v1》第 4 步、《产品计划》§八（全款预付托管与最低成行总价）、§二十二（取消、爽约与船长保底机制）与第 3 步评审（docs/step3-review-78214bbb.md，有条件通过）。本步做成团核算与履约闭环；退改的资金执行继续走第 3 步支付适配层+沙盒，不接真实通道。

## 交付物

### 1. 后端（server/ 扩展，新增迁移自 005 起）
- **成团核算**：班次设成团确认点=出航前一日 18:00（Asia/Shanghai）。确认时按正本 §二十二口径核算：**已售票款 + 违约金补偿池 ≥ 最低成行总价** → 成团（订单转待出航）；不足 → 进入未拼满处置链。注：最低成行总价的净/毛定义待创始人按 D02 裁定，裁定后本公式同步修订（见 docs/muse-response-to-dot-review-2026-10-24.md）。
- **未拼满处置链（四级，顺序执行，金额整数分 *_fen）**：①少人成行（船长确认即可成行，金额口径不变）；②自愿平摊补差（按正本 §八口径：差额=最低成行总价−（已售票款＋补偿池），向全体已订者报价每人补额（均摊到分，尾差按订单顺序逐单 +1 分补齐），仅接受者实际扣款，接受总额达到差额才成行；拒绝者全额退款退出，接受额不足则整体转下一级）；③包船兜底（按正本 §八口径：任一已订钓友或外部用户付整船价转包船，散客全额退款＋平台补偿券记录（券为第 6 步券体系预留字段）；包船方勾选「愿意继续拼」时散客保留原位、不退款。平台不承担默认出资义务）；④自动取消全退（前三级均未达成：已付金额全额退回，订单转已取消）。每级决策与金额留审计记录（谁决策、何时、金额），取消/退款走支付适配沙盒流水。
- **阶梯退改**：乘客主动取消按正本 §二十二定版阶梯（平台模板，字段化配置；以出航时刻 T 为基准、区间左开右闭）：距 T >72h 免费取消全退；(24h,72h] 扣 30%；(6h,24h] 扣 60%；≤6h 不退（违约金全归船长，平台不抽，计入船长应收池字段）；取消后座位回 available，违约金先入该班次补偿池（见成团核算）。爽约（No-show）按不退口径处理。
- **候补递补**：已满班次开放候补登记（按时间顺序队列）；有座位释放（取消/退改）时按队列自动提示（通知走适配层占位），乘客确认后按第 3 步下单链路补单（锁位 10 分钟规则同）。
- **行前清单推送**：成团后自动生成行前清单（集合时间/地点、携带物品、天气提示占位、保险状态、乘船人名单校验），推送走通知适配层（沙盒记录推送内容与接收人，不接真实短信通道）。
- **出航/返航打卡**：船长端出航打卡（时间戳+班次状态转进行中）与返航打卡（转已完成）；打卡前校验班次已成团。
- **实名名单导出**：船长端导出本班次实名名单（姓名、身份证号掩码版与完整版分离：完整版仅船长本人下载且留审计日志，口径与保险报备共用）。

### 2. App（按冻结设计系统）
- 船长端「行程管理」：成团进度（已订金额/最低成行总价）、确认点倒计时、处置操作（少人成行/发起平摊/包船兜底/取消）与金额确认页、打卡按钮、名单导出入口。
- 钓友端订单详情：成团状态、平摊补差确认入口、取消入口（阶梯金额实时算出）、候补登记入口、行前清单页。

## 约束
- 违约金全归船长，平台不截留；金额一律整数分、服务端重算；退款流水走沙盒。
- 不接真实短信/支付生产通道；PII 纪律沿用（完整名单下载留痕）。
- 不得修改规格正本与第 3 步已发布接口口径（新增为主）；一类交付物一提交；节流令沿用。

## 验收（Muse 实跑，对应路线图验收句）
1. 模拟一趟含 4 人取消的班次全流程：四级处置分支各覆盖一例，处置与退款金额逐笔全对（少人成行、平摊补差均摊算例、包船兜底全退+券记录、自动取消全退）。
2. 阶梯退改四档各一例（>72h 免费/72–24h 扣 30%/24–6h 扣 60%/≤6h 不退），含正本算例复验（500 元票出航前 30h 取消：扣 150、退 350）；扣款与船长应收池金额一致；爽约按不退口径。
3. 候补递补：满班→一人取消→候补首位确认补单成功，座位与金额一致。
4. 成团后行前清单生成且内容完整；出航/返航打卡状态流转正确；实名名单导出两版（掩码/完整）与审计日志齐全。
5. **补交第 3 步缺项**：在有可用模拟器的环境补跑第 3 步选位/确认订单/订单详情截图（≥3 张，每张 <1MB），与第 4 步截图一并入仓；CI 保持 analyze+双端构建绿；CI 结果链接附在构建记录中。
- 挂账项（沿用）：真机小额真实订单（含保险真实出单）待创始人并行线（支付商户号、保险签约）到位后补验。
